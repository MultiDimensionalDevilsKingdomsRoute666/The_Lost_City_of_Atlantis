# JacobsHackathon2021

A fork of [RBCodewalker/The_Lost_City_of_Atlantis](https://github.com/RBCodewalker/The_Lost_City_of_Atlantis). It's a Lost City of Atlantis browser game built with the JavaScript Canvas API for a 2021 hackathon.

## What's inside

- `main.js` and `game/`: the game code.
- `Images/`: game art.
- `opening.txt`: the story opening about Atlantis.

## How to play

Open the game page in a browser, or see the upstream live version at https://rbcodewalker.github.io/The_Lost_City_of_Atlantis/.
